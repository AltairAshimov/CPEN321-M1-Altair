# CPEN 321 M1 - Altair

This repository contains the frontend and backend for the CPEN 321 M1 individual assignment.

The application contains three main features:

1. Login + Server Information
2. Live Pixel Art Updates
3. Timer + Gravity Off Surprise

The frontend is a native Android application written in Kotlin using Jetpack Compose.

The backend is written in Node.js and TypeScript and is deployed on Google Cloud.

---

# Requirements

Install the following before starting:

- Git
- Android Studio
- Java 17
- Android SDK API 36
- Node.js 22
- npm

The required Android emulator is:

- Pixel 9
- Android Baklava / Android 16
- API level 36
